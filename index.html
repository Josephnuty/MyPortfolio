My Story

Hello! I'm Joseph Ian Oray, a Second-Year Bachelor of Science in Information Technology (BSIT) student with an enthusiasm for turning ideas into functional, aesthetically appealing digital realities.

My programming journey began with strong foundations in object-oriented programming (OOP) using Java and C++, alongside database modeling with MySQL. Currently, I am deeply focused on front-end web technologies (HTML5, CSS3, modern JavaScript) to design interactive and accessible user experiences.

I believe that great software is created through curiosity, clean code, and user-centered design. I'm always eager to collaborate on real-world projects and learn emerging tools and frameworks.
